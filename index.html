L'Aveugle tend l'oreille

Commandes et réglages
  • ZQSD ou flèches : marcher (peu de bruit)
  • Maj maintenue : courir (très bruyant)
  • F : faire le mort, encore F pour se relever
  • G : grogner · E : manger
  • Rapporte les reliques dans la cabane : arrête-toi devant l'ouverture pour t'y glisser, recule pour sortir

Glisse le doigt pour marcher, plus loin pour courir (bruyant). Rapporte les reliques dans la cabane : arrête-toi devant l'ouverture pour t'y glisser.
